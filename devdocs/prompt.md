# Landing Brief

Build the public-facing surface for **GovCon Bid Desk**, an AI bid-desk operator for government-contracting teams.

## Message

Headline:

```text
Find contracts worth bidding
before the deadline
```

Subhead:

```text
Hire an AI operator that qualifies opportunities, drafts the bid plan, and keeps proposal work moving.
```

CTA:

```text
Start bid review
```

## Public Positioning Rules

- Sell the worker, not the framework.
- Use bid, proposal, contract, opportunity, and action plan language.
- Avoid leading with capture, compliance, MCP, Hermes, or OpenClaw.
- Show the result: pursue / maybe / reject, owners, deadlines, missing inputs, approval gates.

## Preview Cards

Use the dashboard preview to imply the product workflow:

1. **Opportunity fit** - score and decision band.
2. **Search setup** - target market, due window, NAICS, bid capacity.
3. **Action plan** - tasks, owners, questions, review steps.

The landing page is a promise that the product gives the user clarity and motion, not another portal to manage.
