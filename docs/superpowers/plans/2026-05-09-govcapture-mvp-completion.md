# GovCapture MVP Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take GovCapture Agent from its current ~40% state (infrastructure + 2 skills) to a shippable MVP that runs the full §13.1 demo: profile + goal → live agent run → ranked opportunities → action package with human approval gate.

**Architecture:** Build out the missing layers in dependency order. Foundation first (POST write paths + `/web` skeleton + fixture template), then four analysis skills (score_fit, detect_risks, generate_action_package + helpers), then Hermes orchestration (local subprocess invocation matching `tasks/HERMES.md`), then the eval harness, then the product UI consuming the SSE stream, then production hardening.

**Tech Stack:** Python 3.12 / FastAPI / SQLAlchemy 2.0 async / asyncpg / Alembic / Anthropic SDK / Hermes Agent v0.13.0 (local subprocess) / pypdf / reportlab+Pillow (test PDFs) / Redis pub-sub / Supabase (PG + Storage) / Next 15 App Router / React 19 / Tailwind 4 / TypeScript / zod / EventSource API.

**Phase Map:**
- **Phase 0** — Pre-flight: POST analysis routes + `/web` skeleton + fixture template (1 day)
- **Phase 1** — Seeded fixtures: strong-pursue, maybe, reject, adversarial-image (1 day)
- **Phase 2** — Analysis skills: A6 score_fit, A7 detect_risks, A8 generate_action_package (3-4 days)
- **Phase 3** — Discovery + helper skills: A11 search_sam, fetch_attachment, parse_goal, rank, load_seeded (1-2 days)
- **Phase 4** — Hermes integration: subprocess runner + bridge + skill manifests + A10 human review (3-5 days)
- **Phase 5** — Eval harness A12 (1-2 days)
- **Phase 6** — Product UI in `/web` (5-7 days, parallel-able after Phase 0)
- **Phase 7** — Production hardening: transactions, retry, logging, budgets, §11.1 audit (2-3 days)

**Total runway:** ~3 weeks for one engineer; ~2 weeks if Track A (backend) and Track B (frontend) run parallel after Phase 0.

## Conventions

- All tests run via `uv run pytest -v` from repo root (`pyproject.toml` sets `asyncio_mode = "auto"` and `testpaths = ["api/tests"]`).
- Conventional-commit style (`feat:`, `fix:`, `test:`, `chore:`, `docs:`).
- Each task: write failing test → run to confirm fail → implement → run to confirm pass → commit.
- File paths absolute from repo root `/Volumes/CS_Stuff/govcon/`.
- **LLM client class is `LLM`** (not `LLMClient`); **method is `complete_structured`** (not `generate_structured`). All skill imports use `from api.llm import LLM, LLMMetrics`.
- **Skill input/output types use `pydantic.BaseModel`**, matching existing `parse_pdf` and `extract_requirements`. Do NOT use `@dataclass`.
- Existing skills live at `api/skills/<name>/` with `skill.py` (module), `__init__.py` (re-exports), `prompt.txt` (LLM prompts only).

```python
"""load_seeded_opportunities — read /fixtures/*/manifest.json, persist to DB."""
from __future__ import annotations

import json
from pathlib import Path

from pydantic import BaseModel

from api.db.models import Opportunity
from api.repositories.opportunity import OpportunityRepo


class LoadSeededInput(BaseModel):
    slugs: list[str] | None = None  # None = load all


class LoadSeededOutput(BaseModel):
    model_config = {"arbitrary_types_allowed": True}
    opportunities: list[Opportunity]


class LoadSeededSkill:
    def __init__(self, opportunity_repo: OpportunityRepo, fixtures_dir: Path) -> None:
        self._repo = opportunity_repo
        self._dir = fixtures_dir

    async def run(self, payload: LoadSeededInput) -> LoadSeededOutput:
        loaded: list[Opportunity] = []
        for manifest_path in self._discover_manifests(payload.slugs):
            manifest = json.loads(manifest_path.read_text())
            opp_data = dict(manifest["opportunity"])
            opp_data["slug"] = manifest["slug"]
            opp_data["source_notice_id"] = manifest["opportunity"]["solicitation_number"]
            existing = await self._repo.get_by_slug(manifest["slug"])
            if existing:
                loaded.append(existing)
                continue
            opp = await self._repo.create(opp_data)
            loaded.append(opp)
        return LoadSeededOutput(opportunities=loaded)

    def _discover_manifests(self, slugs: list[str] | None):
        for fixture_dir in sorted(self._dir.iterdir()):
            if fixture_dir.name.startswith("_") or fixture_dir.name.startswith("."):
                continue
            if not fixture_dir.is_dir():
                continue
            if slugs is not None and fixture_dir.name not in slugs:
                continue
            manifest = fixture_dir / "manifest.json"
            if manifest.exists():
                yield manifest
```

```python
"""§11.1 deterministic eligibility short-circuit — single source of truth.

Used by score_fit (pre-LLM) and the post-run audit (Phase 7). Returns the list
of blockers if eligibility is not met, or None if eligibility is clear.
"""
from __future__ import annotations

ELIGIBILITY_BLOCKER_TYPES = frozenset({"eligibility", "security", "certification"})
SET_ASIDE_KEYWORDS = ("8(a)", "hubzone", "wosb", "edwosb", "sdvosb", "vosb")
CLEARANCE_KEYWORDS = ("secret", "ts/sci", "top secret", "clearance")


def check_eligibility_short_circuit(
    profile: dict, requirements: list[dict]
) -> list[str] | None:
    """Return list of blockers if §11.1 trips, else None.

    A list is returned whenever eligibility is uncertain or a known mismatch
    exists — score_fit must score 0 in that case (decision=reject).
    """
    blockers: list[str] = []
    company_certs = {c.lower() for c in profile.get("certifications", [])}
    company_clearance = (profile.get("clearance_status") or "none").lower()

    for req in requirements:
        if req.get("type") not in ELIGIBILITY_BLOCKER_TYPES:
            continue
        text = (
            f"{req.get('title', '')} {req.get('value', '')} {req.get('description', '')}"
        ).lower()

        for keyword in SET_ASIDE_KEYWORDS:
            if keyword in text and not any(keyword in c for c in company_certs):
                blockers.append(
                    f"Set-aside requires {keyword.upper()}; company is not certified."
                )

        for kw in CLEARANCE_KEYWORDS:
            if kw in text and company_clearance == "none":
                blockers.append(
                    f"Clearance required ({req.get('title', '')}) — company has none."
                )
                break

        if req.get("type") == "eligibility" and req.get("confidence") in {"low", "unknown"}:
            blockers.append(
                f"Eligibility uncertain: {req.get('title', '')} (low/unknown confidence)."
            )

        if req.get("is_blocker") and req.get("type") in ELIGIBILITY_BLOCKER_TYPES:
            blockers.append(req.get("title", "Unnamed eligibility blocker"))

    seen: set[str] = set()
    unique = [b for b in blockers if not (b in seen or seen.add(b))]
    return unique or None
```

```python
"""score_fit — §5.7 rubric + §11.1 deterministic short-circuit (pre-LLM)."""
from __future__ import annotations

import json
from pathlib import Path
from typing import Any, Literal

from pydantic import BaseModel, Field

from api.llm import LLM, LLMMetrics
from api.policy.eligibility import check_eligibility_short_circuit

PROMPT_PATH = Path(__file__).parent / "prompt.txt"
RAW_PROMPT = PROMPT_PATH.read_text()
_SYSTEM_TAG = "### SYSTEM ###"
_USER_TAG = "### USER ###"
SYSTEM_PROMPT = RAW_PROMPT.split(_SYSTEM_TAG, 1)[1].split(_USER_TAG, 1)[0].strip()
USER_TEMPLATE = RAW_PROMPT.split(_USER_TAG, 1)[1].strip()


class ScoreFitInput(BaseModel):
    company_profile: dict[str, Any]
    requirements: list[dict[str, Any]]


class ScoreFitOutput(BaseModel):
    total_score: int = Field(..., ge=0, le=100)
    decision: Literal["strong_pursue", "pursue", "maybe", "reject"]
    confidence: Literal["high", "medium", "low"]
    score_breakdown: dict[str, int]
    strengths: list[str]
    weaknesses: list[str]
    blockers: list[str]
    missing_information: list[str]
    recommended_next_action: str
    metrics: LLMMetrics


def _band_from_score(score: int) -> Literal["strong_pursue", "pursue", "maybe", "reject"]:
    if score >= 85:
        return "strong_pursue"
    if score >= 70:
        return "pursue"
    if score >= 55:
        return "maybe"
    return "reject"


_OUTPUT_SCHEMA = {
    "type": "object",
    "required": ["total_score", "decision", "confidence", "score_breakdown",
                 "strengths", "weaknesses", "blockers", "missing_information",
                 "recommended_next_action"],
    "properties": {
        "total_score": {"type": "integer", "minimum": 0, "maximum": 100},
        "decision": {"enum": ["strong_pursue", "pursue", "maybe", "reject"]},
        "confidence": {"enum": ["high", "medium", "low"]},
        "score_breakdown": {"type": "object"},
        "strengths": {"type": "array", "items": {"type": "string"}},
        "weaknesses": {"type": "array", "items": {"type": "string"}},
        "blockers": {"type": "array", "items": {"type": "string"}},
        "missing_information": {"type": "array", "items": {"type": "string"}},
        "recommended_next_action": {"type": "string"},
    },
}


class ScoreFitSkill:
    def __init__(self, llm: LLM) -> None:
        self._llm = llm

    async def run(self, payload: ScoreFitInput) -> ScoreFitOutput:
        # §11.1 deterministic short-circuit BEFORE any LLM call.
        blockers = check_eligibility_short_circuit(
            payload.company_profile, payload.requirements
        )
        if blockers:
            return ScoreFitOutput(
                total_score=0,
                decision="reject",
                confidence="high",
                score_breakdown={
                    "capability": 0, "eligibility": 0, "naics": 0,
                    "past_performance": 0, "certification": 0,
                    "insurance_bonding": 0, "deadline": 0,
                    "complexity": 0, "geography": 0,
                },
                strengths=[],
                weaknesses=[],
                blockers=blockers,
                missing_information=[],
                recommended_next_action=(
                    "Do not pursue. Critical eligibility blocker(s) present."
                ),
                metrics=LLMMetrics(
                    model="none", latency_ms=0, cost_usd=0.0,
                    input_tokens=0, output_tokens=0,
                    cache_read_tokens=0, cache_creation_tokens=0, attempts=0,
                ),
            )

        user_prompt = USER_TEMPLATE.format(
            company_profile_json=json.dumps(payload.company_profile, indent=2),
            requirements_json=json.dumps(payload.requirements, indent=2),
        )
        result, metrics = await self._llm.complete_structured(
            system=SYSTEM_PROMPT,
            user=user_prompt,
            schema=_OUTPUT_SCHEMA,
        )
        result["decision"] = _band_from_score(int(result["total_score"]))
        return ScoreFitOutput(**result, metrics=metrics)
```

```python
from pathlib import Path
from typing import Any, Literal

from pydantic import BaseModel

from api.llm import LLM, LLMMetrics

PROMPT_PATH = Path(__file__).parent / "prompt.txt"
RAW_PROMPT = PROMPT_PATH.read_text()
_SYSTEM_TAG = "### SYSTEM ###"
_USER_TAG = "### USER ###"
SYSTEM_PROMPT = RAW_PROMPT.split(_SYSTEM_TAG, 1)[1].split(_USER_TAG, 1)[0].strip()
USER_TEMPLATE = RAW_PROMPT.split(_USER_TAG, 1)[1].strip()

ALLOWED_CATEGORIES = frozenset({
    "clearance_required", "set_aside_mismatch", "certification_gap",
    "past_performance_weakness", "deadline_too_close", "missing_attachments",
    "submission_ambiguity", "insurance_bonding_gap", "scope_mismatch",
    "legal_compliance_review", "pricing_complexity", "missing_required_document",
})


class RiskFlag(BaseModel):
    category: str
    severity: Literal["critical_blocker", "major_risk", "moderate_risk", "minor_concern"]
    title: str
    description: str
    evidence: str
    mitigation: str
    requires_human_review: bool


class DetectRisksInput(BaseModel):
    company_profile: dict[str, Any]
    requirements: list[dict[str, Any]]
    opportunity: dict[str, Any]


class DetectRisksOutput(BaseModel):
    risks: list[RiskFlag]
    metrics: LLMMetrics


_OUTPUT_SCHEMA = {
    "type": "object",
    "required": ["risks"],
    "properties": {
        "risks": {
            "type": "array",
            "items": {
                "type": "object",
                "required": ["category", "severity", "title", "description",
                             "evidence", "mitigation", "requires_human_review"],
                "properties": {
                    "category": {"type": "string"},
                    "severity": {"enum": ["critical_blocker", "major_risk",
                                          "moderate_risk", "minor_concern"]},
                    "title": {"type": "string"},
                    "description": {"type": "string"},
                    "evidence": {"type": "string"},
                    "mitigation": {"type": "string"},
                    "requires_human_review": {"type": "boolean"},
                },
            },
        }
    },
}


class DetectRisksSkill:
    def __init__(self, llm: LLM) -> None:

            requirements_json=json.dumps(payload.requirements, indent=2),
        )
        result, metrics = await self._llm.complete_structured(

            user=user_prompt,

        risks: list[RiskFlag] = []

            risks.append(RiskFlag(**r))
        return DetectRisksOutput(risks=risks, metrics=metrics)
```

```python
)


class GenerateActionPackageInput(BaseModel):
    mode: Literal["full", "reject_summary"]
    company_profile: dict[str, Any]
    opportunity: dict[str, Any]
    requirements: list[dict[str, Any]]
    fit_score: dict[str, Any]
    risks: list[dict[str, Any]]


class ActionPackageOutput(BaseModel):
    executive_summary: str
    decision: str
    fit_score: int
    fit_rationale: str
    compliance_matrix: list[dict[str, Any]]
    risk_register: list[dict[str, Any]]
    proposal_checklist: list[str]
    timeline: list[dict[str, Any]]
    partner_suggestions: list[dict[str, Any]]
    outreach_draft: dict[str, Any] | None
    human_approval_required: list[str]
    metrics: LLMMetrics


_OUTPUT_SCHEMA = {
    "type": "object",
    "required": ["executive_summary", "decision", "fit_score", "fit_rationale",
                 "compliance_matrix", "risk_register", "proposal_checklist",
                 "timeline", "partner_suggestions", "human_approval_required"],
    "properties": {
        "executive_summary": {"type": "string"},
        "decision": {"type": "string"},
        "fit_score": {"type": "integer"},
        "fit_rationale": {"type": "string"},
        "compliance_matrix": {"type": "array"},
        "risk_register": {"type": "array"},
        "proposal_checklist": {"type": "array", "items": {"type": "string"}},
        "timeline": {"type": "array"},
        "partner_suggestions": {"type": "array"},
        "outreach_draft": {"type": ["object", "null"]},
        "human_approval_required": {"type": "array", "items": {"type": "string"}},
    },
}


class GenerateActionPackageSkill:
    def __init__(self, llm: LLM) -> None:
        self._llm = llm

    async def run(self, payload: GenerateActionPackageInput) -> ActionPackageOutput:
        if payload.mode == "reject_summary":
            return self._reject_summary(payload)
        return await self._full(payload)

    def _reject_summary(self, p: GenerateActionPackageInput) -> ActionPackageOutput:
        blockers = p.fit_score.get("blockers", [])
        opp_title = p.opportunity.get("title", "this opportunity")
        return ActionPackageOutput(
            executive_summary=(
                f"Do not pursue {opp_title}. Critical eligibility blocker(s): "
                f"{'; '.join(blockers) or 'see fit score'}."
            ),
            decision="reject",
            fit_score=int(p.fit_score.get("total_score", 0)),
            fit_rationale=f"Eligibility short-circuit (§11.1). Blockers: {blockers}",
            compliance_matrix=[],
            risk_register=[
                {
                    "risk": b, "severity": "critical", "explanation": "",
                    "mitigation": (
                        "Out of scope — pursue only if certification/clearance acquired."
                    ),
                }
                for b in blockers
            ],
            proposal_checklist=[],
            timeline=[],
            partner_suggestions=[],
            outreach_draft=None,
            human_approval_required=[
                f"Critical eligibility blocker(s) detected for {opp_title}. {DEFAULT_APPROVAL}"
            ],
            metrics=LLMMetrics(
                model="none", latency_ms=0, cost_usd=0.0,
                input_tokens=0, output_tokens=0,
                cache_read_tokens=0, cache_creation_tokens=0, attempts=0,
            ),
        )

    async def _full(self, p: GenerateActionPackageInput) -> ActionPackageOutput:
        user_prompt = USER_TEMPLATE.format(
            opportunity_json=json.dumps(p.opportunity, indent=2),
            company_profile_json=json.dumps(p.company_profile, indent=2),
            requirements_json=json.dumps(p.requirements, indent=2),
            fit_score_json=json.dumps(p.fit_score, indent=2),
            risks_json=json.dumps(p.risks, indent=2),
        )
        result, metrics = await self._llm.complete_structured(
            system=SYSTEM_PROMPT,
            user=user_prompt,
            schema=_OUTPUT_SCHEMA,
        )
        if not result.get("human_approval_required"):
            result["human_approval_required"] = [DEFAULT_APPROVAL]
        return ActionPackageOutput(**result, metrics=metrics)
```
