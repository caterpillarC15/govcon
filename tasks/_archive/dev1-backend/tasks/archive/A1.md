# A1 — FastAPI skeleton + native local dev stack

> **Status:** ✅ Done 2026-05-09. Skeleton boots, `/healthz` green, `hermes --version` returns `v0.13.0 (2026.5.7)`. **Deviations from spec:** local Postgres is **17** (not 16); spec/Makefile still pin 16, which is fine on machines that have either — same major-version family for our schema. **Mock server (P0.6) does not exist** and was not needed: A3's pre-A9 SSE replayer at `api/agent/replay.py` already provides Dev 2 with a real event stream, so no canned-routes migration is required.
>
> **PRD v1.2.3 (later same day):** Postgres moved off-box to Supabase (PRD §7.5). Local Postgres on `localhost:5432` still works as a dev fallback — `api/db/__init__.py` only adds `ssl=require` for non-localhost hosts. The `services-up`/`services-down` Makefile targets are now optional for production-like dev (Supabase is always-on); Redis is the only service that still needs to run locally for the SSE bridge.

**Goal:** A FastAPI app boots on `:8000` against a native Postgres on `:5432` and native Redis on `:6379`. `/healthz` returns 200. The mock-server canned routes from P0.6 keep working — A3 replaces them later.

**PRD references:** §7.2, §7.5, §7.6.
**Depends on:** Phase 0.
**Blocks:** A2, A3, A4, A9, A11, A12, A13.

> **No Docker.** Per the 2026-05-09 decision, both local dev and the VX1 prod box run Postgres, Redis, and the FastAPI app as native services (Homebrew on macOS, apt + systemd on Ubuntu). There is no `Dockerfile`, no `docker-compose.yaml`. Hermes runs as a subprocess of the FastAPI process on the same host.

## Prerequisites (one-time, per dev machine)

**macOS:**

```bash
brew install postgresql@16 redis python@3.12 uv
brew services start postgresql@16
brew services start redis
createuser -s govcon
createdb -O govcon govcon
```

**Ubuntu (matches VX1):**

```bash
sudo apt-get install -y postgresql-16 redis-server python3.12 python3.12-venv
sudo systemctl enable --now postgresql redis-server
sudo -u postgres createuser -s govcon
sudo -u postgres createdb -O govcon govcon
curl -LsSf https://astral.sh/uv/install.sh | sh   # uv for Python deps
```

Confirm: `psql -U govcon -d govcon -c 'select 1'` returns 1, `redis-cli ping` returns `PONG`.

## Skeleton: `/api/main.py`

```python
from contextlib import asynccontextmanager
from fastapi import FastAPI

from api.config import settings
from api.db import engine, init_db, close_db
from api.redis import redis_client, close_redis
from api.routes import healthz, company_profiles, agent_runs, opportunities, action_packages


@asynccontextmanager
async def lifespan(app: FastAPI):
    await init_db()
    # Mock SSE replay registers here until A9 ships
    yield
    await close_db()
    await close_redis()


app = FastAPI(title="GovCapture API", version="0.1.0", lifespan=lifespan)

app.include_router(healthz.router)
app.include_router(company_profiles.router)
app.include_router(agent_runs.router)
app.include_router(opportunities.router)
app.include_router(action_packages.router)
```

## Skeleton: `/api/config.py`

```python
from functools import lru_cache
from pydantic import Field
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", extra="ignore")

    anthropic_api_key: str = Field(..., alias="ANTHROPIC_API_KEY")
    sam_api_key: str = Field("", alias="SAM_API_KEY")
    database_url: str = Field(..., alias="DATABASE_URL")
    redis_url: str = Field(..., alias="REDIS_URL")
    hermes_home: str = Field("/var/lib/hermes", alias="HERMES_HOME")
    hermes_model: str = Field("claude-sonnet-4-6", alias="HERMES_MODEL")

    llm_dev_model: str = Field("claude-haiku-4-5-20251001", alias="LLM_DEV_MODEL")
    llm_synth_model: str = Field("claude-sonnet-4-6", alias="LLM_SYNTH_MODEL")

    run_budget_usd: float = Field(0.50, alias="RUN_BUDGET_USD")
    run_budget_steps: int = Field(40, alias="RUN_BUDGET_STEPS")
    run_budget_seconds: int = Field(360, alias="RUN_BUDGET_SECONDS")

    demo_use_seeded_only: bool = Field(False, alias="DEMO_USE_SEEDED_ONLY")


@lru_cache
def get_settings() -> Settings:
    return Settings()  # raises on missing required vars at startup


settings = get_settings()
```

This is the **only** file allowed to read `os.environ`. Everywhere else imports `settings`.

For local dev, `.env` should look like:

```
ANTHROPIC_API_KEY=sk-ant-...
DATABASE_URL=postgresql+asyncpg://govcon@localhost:5432/govcon
REDIS_URL=redis://localhost:6379/0
HERMES_HOME=~/.hermes
```

## Skeleton: `/api/db.py`

```python
from sqlalchemy import text
from sqlalchemy.ext.asyncio import AsyncEngine, async_sessionmaker, create_async_engine

from api.config import settings


engine: AsyncEngine = create_async_engine(settings.database_url, echo=False, pool_pre_ping=True)
SessionLocal = async_sessionmaker(engine, expire_on_commit=False)


async def init_db() -> None:
    # Light readiness check — actual schema is owned by Alembic (A2)
    async with engine.connect() as conn:
        await conn.execute(text("select 1"))


async def close_db() -> None:
    await engine.dispose()
```

## Skeleton: `/api/redis.py`

```python
import redis.asyncio as aioredis

from api.config import settings


redis_client = aioredis.from_url(settings.redis_url, decode_responses=True)


async def close_redis() -> None:
    await redis_client.close()
```

## Skeleton: `/api/routes/healthz.py`

```python
from fastapi import APIRouter
from sqlalchemy import text

from api.db import engine
from api.redis import redis_client


router = APIRouter(tags=["health"])


@router.get("/healthz")
async def healthz() -> dict[str, str]:
    # Light dependency check — fail fast if DB or Redis is wedged
    async with engine.connect() as conn:
        await conn.execute(text("select 1"))
    await redis_client.ping()
    return {"status": "ok"}
```

## Skeleton: top-level `Makefile` (initial targets)

```make
.PHONY: dev services-up services-down logs schemas migrate test

dev:                       ## Run the FastAPI app with --reload (assumes services up)
	uv run uvicorn api.main:app --reload --host 0.0.0.0 --port 8000

services-up:               ## Start native Postgres + Redis (idempotent)
	@if command -v brew >/dev/null 2>&1; then \
	  brew services start postgresql@16; \
	  brew services start redis; \
	else \
	  sudo systemctl start postgresql redis-server; \
	fi

services-down:             ## Stop native Postgres + Redis
	@if command -v brew >/dev/null 2>&1; then \
	  brew services stop postgresql@16; \
	  brew services stop redis; \
	else \
	  sudo systemctl stop postgresql redis-server; \
	fi

logs:                      ## Tail Postgres logs (Redis is usually quiet)
	@if command -v brew >/dev/null 2>&1; then \
	  tail -F "$$(brew --prefix)/var/log/postgresql@16.log"; \
	else \
	  journalctl -u postgresql -f; \
	fi

schemas:
	# (added in P0.2)
	@echo "schema codegen targets land in P0.2"

migrate:
	# (added in A2)
	@echo "alembic targets land in A2"

test:
	uv run pytest -v api/tests
```

## Hermes install (per host, not per container)

Hermes is a Python package + CLI binary. Install once per machine; FastAPI invokes it as a subprocess. There is no Docker involved.

```bash
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
hermes model    # configure the active model (claude-sonnet-4-6 in dev)
hermes --version
```

Hermes' executable lands in `~/.local/bin/hermes` on macOS dev boxes and `/home/govcon/.local/bin/hermes` on the VX1 (installed by `infra/bootstrap.sh` in A13).

## Pitfalls

- **`asyncpg` vs `psycopg`:** if you pick `asyncpg`, the URL prefix is `postgresql+asyncpg://`. Don't mix them.
- **Port collisions:** something already on `:5432` or `:6379` (a stale Postgres install, an existing redis-cli) will fail with confusing connection errors. `lsof -i :5432` to check.
- **Postgres version drift:** macOS dev on `postgresql@16`, VX1 on `postgresql-16` — same major version. Don't mix 15 and 16.
- **`brew services` quirks:** if `brew services start` returns OK but the service isn't actually running, check `brew services list` and `~/Library/LaunchAgents` for stale plist files.
- **Env vars typed as the wrong type:** Pydantic settings will silently coerce. Test that booleans parse correctly (`DEMO_USE_SEEDED_ONLY=false` → `False`).
- **Forgetting to run `make services-up` after a reboot.** macOS reboots stop brew services unless they're in `--all` mode; symptoms are connection-refused on `:5432`. Add `make services-up` to your dev startup ritual.
