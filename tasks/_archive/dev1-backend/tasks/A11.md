## SAM.gov v2 search

Endpoint: `https://api.sam.gov/opportunities/v2/search`. Requires `SAM_API_KEY`.

Query params we use:

| Param | Source |
|-------|--------|
| `keywords` | parsed from goal |
| `naics` | profile NAICS or extracted goal hints |
| `setAside` | profile small_business_status / certifications |
| `placeOfPerformance.state` | profile location/service_area or "TX" if Texas-track |
| `postedFrom`, `postedTo` | within last 30 days by default |
| `responseDeadLineFrom`, `responseDeadLineTo` | due-date window from goal |
| `limit` | 50 (paginate via offset if needed) |

```python
import httpx
from datetime import date, timedelta

from api.config import settings


async def search_sam_opportunities(
    keywords: str,
    naics: list[str] | None = None,
    set_aside: str | None = None,
    state: str | None = None,
    deadline_within_days: int = 60,
) -> list[Opportunity]:
    params = {
        "api_key": settings.sam_api_key,
        "q": keywords,
        "limit": 50,
        "responseDeadLineFrom": date.today().isoformat(),
        "responseDeadLineTo": (date.today() + timedelta(days=deadline_within_days)).isoformat(),
    }
    if naics: params["naics"] = ",".join(naics)
    if set_aside: params["setAside"] = set_aside
    if state: params["placeOfPerformance.state"] = state

    async with httpx.AsyncClient(timeout=20.0) as http:
        resp = await http.get(SAM_URL, params=params)
        if resp.status_code == 429:
            raise ToolError("rate_limited", "SAM.gov rate limit hit")
        resp.raise_for_status()
        return _normalize_results(resp.json())
```

## Caching

Cache key: `(keywords, naics, set_aside, state, date)` — recompute daily. Store in Postgres (`opportunity_search_cache` table) or Redis. Postgres is fine for v1.

```sql
CREATE TABLE opportunity_search_cache (
    cache_key TEXT PRIMARY KEY,
    payload JSONB NOT NULL,
    created_at TIMESTAMPTZ DEFAULT now()
);
```

Cache lookup before the live call. Any cache <24h old is served. Insert after a successful live call.

## Seeded loader

```python
from pathlib import Path
import json

from api.config import settings


FIXTURES_DIR = Path(__file__).parent.parent.parent.parent / "fixtures"


async def load_seeded_opportunities(
    keywords: str | None = None,
    state: str | None = None,
    naics: list[str] | None = None,
) -> list[Opportunity]:
    """Load all fixtures matching given filters."""
    results: list[Opportunity] = []
    for fixture_dir in FIXTURES_DIR.iterdir():
        if fixture_dir.name.startswith("_") or fixture_dir.name == "adversarial-image-pdf":
            continue  # skip template + adversarial unless explicitly requested
        opportunity_path = fixture_dir / "opportunity.json"
        if not opportunity_path.exists():
            continue
        opp = Opportunity.model_validate_json(opportunity_path.read_text())

        # Loose filtering — for v1, match if no filters or any keyword overlap
        if keywords:
            kws = keywords.lower().split()
            haystack = (opp.title + " " + opp.description).lower()
            if not any(kw in haystack for kw in kws):
                continue
        if naics and opp.naics not in naics:
            continue
        if state and (opp.place_of_performance or "").lower() != state.lower():
            continue

        results.append(opp)
    return results
```

## Fallback hierarchy

PRD §5.4: **live → cached → seeded → user-uploaded**. The planner chooses based on these recovery rules:

```python
def recovery_for(tool, exc):
    if tool == "search_sam_opportunities" and exc.code == "rate_limited":
        return Recovery(status="degraded", fatal=False, fallback_tool="load_seeded_opportunities")
    if tool == "search_sam_opportunities" and exc.code in ("5xx", "timeout"):
        return Recovery(status="degraded", fatal=False, fallback_tool="load_seeded_opportunities")
```

The planner sees the fallback and calls `load_seeded_opportunities` automatically.

## DEMO_USE_SEEDED_ONLY

When this env flag is true (set on VX1 for the stage), `search_sam_opportunities` is excluded from the registry entirely — the planner won't even consider live calls. The seeded path is the only path. PRD §13.1 backup demo strategy.

## Pitfalls

- **SAM API key per environment.** Dev key, prod key. Don't commit either.
- **SAM responses change shape sometimes.** `_normalize_results` should be defensive — log unrecognized fields, don't crash.
- **Date formats.** SAM expects ISO `YYYY-MM-DD`. Don't pass naive datetimes.
- **Rate limits are aggressive.** Per-key limits drop fast under demo iteration. Cache hard. Default to seeded during dev.
- **Test isolation.** Don't hit live SAM in CI. Mock the `httpx.AsyncClient` in tests.
