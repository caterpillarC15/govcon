## Form fields (PRD §5.1)

All required unless noted:

- Company name
- Company website (optional)
- Company description (textarea, ~200 words guidance)
- Capabilities (tag input, autocomplete from common list)
- Industry keywords (tag input)
- Location (city, state)
- Service area (multi-select of states, plus "Federal — civilian", "Federal — defense")
- NAICS codes (tag input with format validation `\d{6}`, optional)
- Certifications (multi-select: 8(a), HUBZone, WOSB, EDWOSB, SDVOSB, VOSB, CMMC L1/L2/L3, ISO 9001, ISO 27001, FedRAMP)
- Small business status (boolean)
- SAM registration status (select: active, expired, none)
- Clearance status (select: none, secret, top_secret)
- Past performance (list, each with agency, contract value USD, year, scope text)
- Insurance/bonding status (free text, optional)
- Preferred contract size (select: under_500k, 500k_2m, 2m_10m, over_10m)
- Preferred role (radio: prime, subcontractor, either)

## Paste-mode parsing

Client-side regex for common patterns. Don't try to be perfect; user reviews before saving.

```tsx
function parsePastedProfile(text: string): Partial<CompanyProfile> {
  const result: Partial<CompanyProfile> = {};

  // Name (first line, often)
  const firstLine = text.split("\n").map(l => l.trim()).find(l => l.length > 0);
  if (firstLine && firstLine.length < 100) result.name = firstLine;

  // NAICS codes
  const naicsMatches = [...text.matchAll(/\b(\d{6})\b/g)].map(m => m[1]);
  if (naicsMatches.length) result.naics_codes = [...new Set(naicsMatches)];

  // Certifications (loose)
  const certs: string[] = [];
  if (/\b8\(a\)/.test(text)) certs.push("8(a)");
  if (/\bHUBZone\b/i.test(text)) certs.push("HUBZone");
  if (/\bWOSB\b/i.test(text)) certs.push("WOSB");
  if (/\bSDVOSB\b/i.test(text)) certs.push("SDVOSB");
  if (/\bCMMC\s*Level?\s*([123])\b/i.test(text)) {
    const lvl = text.match(/CMMC\s*Level?\s*([123])/i)?.[1];
    certs.push(`CMMC Level ${lvl}`);
  }
  if (certs.length) result.certifications = certs;

  // Clearance
  if (/\btop\s*secret\b/i.test(text)) result.clearance_status = "top_secret";
  else if (/\bsecret\b/i.test(text)) result.clearance_status = "secret";

  // Capabilities — keyword harvest
  const capabilityHints = ["cybersecurity", "software development", "cloud", "infrastructure",
    "data analytics", "AI/ML", "facilities maintenance", "logistics", "training", "consulting"];
  result.capabilities = capabilityHints.filter(c => text.toLowerCase().includes(c));

  // Description: middle bulk of text
  result.description = text.split("\n").slice(1, 6).join(" ").trim().slice(0, 1000);

  return result;
}
```

## Pitfalls

- **Certification string drift.** A6's eligibility scoring matches strings literally. If B writes "8a" and A checks "8(a)", reject fixture won't reject. Use a controlled multi-select; align with A.
- **Past performance year as string.** Coerce to number before submit.
- **Form perf with large past_performance lists.** Use a list with proper `key={id}`; don't re-render the whole form per row.
- **Mobile layout.** Desktop is fine for v1, but at narrow widths the form should stack. Use Tailwind `md:` breakpoints.
