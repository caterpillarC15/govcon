## Authoring the image-only PDF

Two methods:

1. **Render text PDF, then convert to image, then re-embed in PDF.**
   - Take the strong-pursue solicitation PDF.
   - `pdftoppm -r 150 strong-pursue.pdf out` → produces `out-1.png`, `out-2.png`.
   - `convert out-*.png solicitation.pdf` (ImageMagick) → image-only PDF.
   - Verify: `pypdf` should return < 50 chars total.

2. **Screenshot a doc and save as PDF directly.**
   - Open any doc; full-screen screenshot per page.
   - Concat into a PDF via Preview (Mac) or `convert`.

Verify text-extraction is empty:

```bash
python -c "import pypdf; r=pypdf.PdfReader('attachments/solicitation.pdf'); print(len(r.pages[0].extract_text()))"
# Should print 0 or a very small number.
```

## Pitfalls

- **PDF still has a text layer somehow.** Some converters preserve invisible text. Run `pdftotext` on the result to confirm; should be empty.
- **File too large.** A high-DPI image PDF can be 5+ MB. Compress with `convert -density 100 -compress jpeg -quality 70`. We don't need pretty.
- **Including the adversarial in the live demo.** Don't. It's eval-only. Demo only shows the three pursue/maybe/reject fixtures.
