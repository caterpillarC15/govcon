## Recording the backup video

Use Loom, ScreenFlow, or QuickTime:

1. Set up the demo profile + goal.
2. Hit Record.
3. Run the full §13.1 script with no fumbles.
4. Save to `web/public/demo/backup-run.mp4` (≤ 50 MB).
5. Test it plays from the URL `https://<vercel-app>/demo/backup-run.mp4`.

Re-record if you fluff a major beat. The audience won't see a recording, but if you have to play it on stage, it needs to be clean.

## Pitfalls

- **Demo gods.** Live SAM.gov calls fail at the worst time. `DEMO_USE_SEEDED_ONLY=true` prevents this.
- **Forgetting to pre-warm the browser.** Hit each demo URL once before going on stage so caches are warm. The first agent run after a cold deploy can be slow.
- **Forgetting to clear Hermes memory between rehearsals.** `hermes memory clear` if cross-run contamination affects scoring.
- **Voice over a frozen UI.** If the UI hangs visibly, narrate the recovery path. Don't pause silently.
- **Not practicing the §11.1 click sequence.** This is the demo's most important moment. Click-click-click. Practice until automatic.
