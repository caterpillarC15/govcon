## Pitfalls

- **Schema drift between this profile and `/api/schemas/`.** When schema changes, regenerate and re-validate.
- **Tweaking past_performance number.** $1.5M → $9M would break the maybe fixture's gap. Don't change without re-running eval.
- **Adding certifications that match a reject-fixture set-aside.** Adding `"8(a)"` to certifications would fail the §11.1 test if there's an 8(a) reject fixture. Keep certifications minimal.
- **Inconsistency between profile sources.** If the demo URL pre-fills with one set of values but the eval runs against another, you'll see scoring drift. Single-source it.
