## bootstrap.sh skeleton

```bash
#!/usr/bin/env bash
set -euo pipefail

# Run on fresh Ubuntu 24.04 LTS as root.
# Usage: bash bootstrap.sh <DOMAIN_OR_IP> <EMAIL_FOR_LETSENCRYPT>

DOMAIN="${1:?domain required}"
EMAIL="${2:?email required}"

# 1. System
apt-get update
apt-get install -y --no-install-recommends \
  curl ca-certificates git ufw unattended-upgrades \
  postgresql-client jq

# 2. Firewall
ufw allow 22/tcp
ufw allow 80/tcp
ufw allow 443/tcp
ufw --force enable

# 3. Docker
curl -fsSL https://get.docker.com | sh
usermod -aG docker ubuntu || true

# 4. App user (non-root for runtime)
id -u govcon &>/dev/null || useradd -m -s /bin/bash govcon
usermod -aG docker govcon

# 5. App location
APP_DIR=/opt/govcon
mkdir -p "$APP_DIR"
chown govcon:govcon "$APP_DIR"

# 6. Clone repo
sudo -u govcon git clone https://github.com/<ORG>/govcon.git "$APP_DIR"
cd "$APP_DIR"

# 7. Env file
if [ ! -f .env ]; then
  echo "ERROR: place /opt/govcon/.env with prod values before running this script"
  exit 1
fi

# 8. Hermes runtime (installed inside the api container per A1 Dockerfile;
#    this step is only for sanity-checking on the host)
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash || true

# 9. nginx + certbot (host-level, NOT in compose, so 80/443 stay free for cert renewals)
apt-get install -y nginx certbot python3-certbot-nginx
cp infra/nginx.conf /etc/nginx/sites-available/govcon
ln -sf /etc/nginx/sites-available/govcon /etc/nginx/sites-enabled/govcon
rm -f /etc/nginx/sites-enabled/default
nginx -t
systemctl reload nginx

certbot --nginx --non-interactive --agree-tos --redirect \
  -d "$DOMAIN" --email "$EMAIL"

# 10. Bring up the stack
sudo -u govcon docker compose -f infra/docker-compose.prod.yaml up -d --build

# 11. Wait for healthy
for i in $(seq 1 30); do
  if curl -fsS "https://$DOMAIN/healthz" | grep -q ok; then
    echo "Healthy after $i tries."
    break
  fi
  sleep 5
done

# 12. Cron: daily backups at 03:00
echo "0 3 * * *  govcon /opt/govcon/infra/backup.sh" > /etc/cron.d/govcon-backup
chmod 0644 /etc/cron.d/govcon-backup

# 13. Done
echo "Bootstrap complete. Verify https://$DOMAIN/healthz."
```

## nginx.conf (key bits)

```nginx
upstream api { server 127.0.0.1:8000; }

server {
    listen 80;
    server_name _;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name <DOMAIN>;
    # certbot fills in ssl_certificate and ssl_certificate_key

    # Static frontend (if served from VX1; skip if Vercel-only)
    # location / { proxy_pass http://localhost:3000; }

    # API
    location /api/ {
        proxy_pass http://api/;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # SSE — must disable buffering
    location ~ ^/api/agent-runs/[^/]+/stream$ {
        proxy_pass http://api;
        proxy_set_header Host $host;
        proxy_buffering off;
        proxy_read_timeout 600s;
        proxy_send_timeout 600s;
        chunked_transfer_encoding off;
    }
}
```

## backup.sh

```bash
#!/usr/bin/env bash
set -euo pipefail
TS=$(date -u +%Y%m%dT%H%M%SZ)
DEST=/var/backups/govcon
mkdir -p "$DEST"

# Postgres
docker compose -f /opt/govcon/infra/docker-compose.prod.yaml exec -T postgres \
  pg_dump -U govcon govcon | gzip > "$DEST/postgres-$TS.sql.gz"

# Parsed docs (if persisted to host)
tar -czf "$DEST/parsed-$TS.tar.gz" -C /var/lib/govcapture parsed/ raw/ 2>/dev/null || true

# Off-box: rsync to second host (set BACKUP_REMOTE in /etc/govcon-backup.env)
if [ -f /etc/govcon-backup.env ]; then
  set -a; . /etc/govcon-backup.env; set +a
  rsync -azq "$DEST/" "$BACKUP_REMOTE":/var/backups/govcon/
fi

# Local retention: keep 14 days
find "$DEST" -type f -mtime +14 -delete
```

Test restore quarterly (or before demo): `pg_restore` from yesterday's dump into a clean DB.

## Hermes prod config

- `hermes model` set to `claude-sonnet-4-6` for synthesis path.
- `HERMES_HOME=/var/lib/hermes` mapped as a named volume so memory persists across container rebuilds.
- Hermes' skill-creation feature is OFF by default for this deployment (we want the registered skill set, no surprises).
- LLM API key flows through Hermes via `ANTHROPIC_API_KEY` env var.

## Pitfalls

- **nginx buffering for SSE.** `proxy_buffering off` is non-negotiable on the stream endpoint. Without it the frontend timeline appears frozen until the run completes.
- **Certbot timing.** First-cert acquisition fails if DNS isn't propagated. Either wait or use DNS-challenge.
- **Docker socket permissions.** App user (`govcon`) needs `docker` group membership. Bootstrap handles it; verify with `sudo -u govcon docker ps`.
- **Postgres port exposed publicly.** Don't. Bind only to `127.0.0.1` or remove the host-port mapping in prod compose.
- **Hermes memory volume not mounted.** Without it, every restart wipes Hermes' state. Demo will start cold; usually fine, but be aware.
- **Backups never tested.** Test restore as part of A13 acceptance, not after a disaster.
