# A6 — `score_fit` (with §11.1 enforcement)

**Goal:** Apply PRD §5.7 rubric against extracted requirements + company profile. Produce `FitScoreOutput` (§10.2). **Enforce §11.1 eligibility short-circuit deterministically — capability strengths cannot override eligibility blockers.**

**PRD references:** §5.7, §10.2, §11.1.

## Two-phase design

The fit score has two parts. Keep them separate.

1. **Deterministic math (`score_fit.py`).** Each of the 9 dimensions is a Python function. The total score and decision band come from this — NOT the LLM. The LLM cannot override a deterministic reject.
2. **LLM rationale (`score_fit_rationale.py`).** Given the breakdown + profile + requirements, generate strengths/weaknesses/recommended_next_action prose. The LLM is constrained to explain the decision, not change it.

This split is what keeps §11.1 enforceable.

---

## Dimensions and weights (PRD §5.7)

| Dimension | Weight | Function name |
|-----------|--------|---------------|
| Capability match | 20 | `score_capability` |
| Eligibility / set-aside match | 15 | `score_eligibility` ⚠ §11.1 |
| NAICS / industry match | 10 | `score_naics` |
| Past performance fit | 15 | `score_past_performance` |
| Certification / compliance readiness | 10 | `score_certification` |
| Insurance / bonding readiness | 10 | `score_insurance_bonding` |
| Deadline feasibility | 10 | `score_deadline` |
| Proposal complexity | 5 | `score_complexity` |
| Geography / place-of-performance fit | 5 | `score_geography` |
| **Total** | **100** | — |

Decision bands:
- 85–100: `strong_pursue`
- 70–84: `pursue`
- 55–69: `maybe`
- 0–54: `reject`

**§11.1 override:** if `score_eligibility` returns 0 with a critical blocker, decision is forced to `reject` regardless of total. The total score still computes for transparency, but the decision is locked.

## Skeleton: `score_fit.py`

```python
from dataclasses import dataclass
from datetime import date, timedelta

from api.schemas.company_profile import CompanyProfile
from api.schemas.extracted_requirement import ExtractedRequirement
from api.schemas.fit_score import FitScoreOutput, ScoreBreakdown


@dataclass(frozen=True)
class DimensionResult:
    score: int
    rationale: str
    eligibility_blocker: str | None = None  # only used by score_eligibility


def score_eligibility(
    profile: CompanyProfile, requirements: list[ExtractedRequirement]
) -> DimensionResult:
    """Apply §11.1 conservatism rule. Return 0 + blocker on any hard mismatch."""
    blockers: list[str] = []

    # Set-aside check
    set_aside_reqs = [r for r in requirements if r.type == "eligibility" and "set-aside" in r.title.lower()]
    for req in set_aside_reqs:
        v = req.value.lower()
        if "8(a)" in v and "8(a)" not in [c.lower() for c in profile.certifications]:
            blockers.append("Solicitation requires 8(a) set-aside; profile lacks 8(a) certification.")
        if "hubzone" in v and "hubzone" not in [c.lower() for c in profile.certifications]:
            blockers.append("Solicitation requires HUBZone set-aside; profile not HUBZone certified.")
        if "wosb" in v and "wosb" not in [c.lower() for c in profile.certifications]:
            blockers.append("Solicitation requires WOSB set-aside; profile not WOSB certified.")
        if "sdvosb" in v and "sdvosb" not in [c.lower() for c in profile.certifications]:
            blockers.append("Solicitation requires SDVOSB set-aside; profile not SDVOSB certified.")

    # Clearance check
    clearance_reqs = [r for r in requirements if r.type == "security"]
    for req in clearance_reqs:
        v = (req.value + " " + req.description).lower()
        if "secret" in v and profile.clearance_status != "secret":
            blockers.append(f"Solicitation requires Secret clearance; profile clearance: {profile.clearance_status or 'none'}.")
        if "top secret" in v and profile.clearance_status not in ("top_secret",):
            blockers.append(f"Solicitation requires Top Secret clearance; profile clearance: {profile.clearance_status or 'none'}.")

    # Critical-blocker requirements directly from extraction
    for req in requirements:
        if req.is_blocker and req.confidence in ("high", "medium"):
            blockers.append(f"Critical blocker (extracted): {req.title} — {req.value}")

    if blockers:
        return DimensionResult(
            score=0,
            rationale=f"Eligibility short-circuit (§11.1): {'; '.join(blockers[:3])}",
            eligibility_blocker="; ".join(blockers),
        )

    return DimensionResult(score=15, rationale="No hard eligibility blockers detected.")


def score_capability(profile: CompanyProfile, requirements: list[ExtractedRequirement]) -> DimensionResult:
    tech_reqs = [r for r in requirements if r.type == "technical"]
    if not tech_reqs:
        return DimensionResult(score=10, rationale="No specific technical requirements extracted; partial credit.")

    profile_caps = [c.lower() for c in profile.capabilities]
    matches = sum(
        1 for r in tech_reqs
        if any(cap in r.title.lower() or cap in r.description.lower() for cap in profile_caps)
    )
    ratio = matches / len(tech_reqs)
    score = int(round(ratio * 20))
    return DimensionResult(score=score, rationale=f"{matches}/{len(tech_reqs)} technical reqs match profile capabilities.")


# ... (similar for naics, past_performance, certification, insurance_bonding, deadline, complexity, geography)


def score_fit(
    profile: CompanyProfile,
    requirements: list[ExtractedRequirement],
    opportunity_due_date: date | None = None,
) -> FitScoreOutput:
    el = score_eligibility(profile, requirements)
    cap = score_capability(profile, requirements)
    naics = score_naics(profile, requirements)  # implement
    pp = score_past_performance(profile, requirements)  # implement
    cert = score_certification(profile, requirements)  # implement
    ins = score_insurance_bonding(profile, requirements)  # implement
    deadline = score_deadline(profile, requirements, opportunity_due_date)  # implement
    complexity = score_complexity(profile, requirements)  # implement
    geo = score_geography(profile, requirements)  # implement

    breakdown = ScoreBreakdown(
        capability=cap.score,
        eligibility=el.score,
        naics=naics.score,
        past_performance=pp.score,
        certification=cert.score,
        insurance_bonding=ins.score,
        deadline=deadline.score,
        complexity=complexity.score,
        geography=geo.score,
    )
    total = sum(breakdown.model_dump().values())

    # §11.1 ENFORCEMENT — eligibility short-circuit
    if el.score == 0 and el.eligibility_blocker:
        decision = "reject"
        blockers = [el.eligibility_blocker]
    else:
        if total >= 85:
            decision = "strong_pursue"
        elif total >= 70:
            decision = "pursue"
        elif total >= 55:
            decision = "maybe"
        else:
            decision = "reject"
        blockers = []

    confidence = _confidence_from_requirements(requirements)

    return FitScoreOutput(
        total_score=total,
        decision=decision,
        confidence=confidence,
        score_breakdown=breakdown,
        strengths=[],         # filled by score_fit_rationale
        weaknesses=[],        # filled by score_fit_rationale
        blockers=blockers,
        missing_information=[],
        recommended_next_action="",  # filled by score_fit_rationale
    )


def _confidence_from_requirements(requirements: list[ExtractedRequirement]) -> str:
    if not requirements:
        return "low"
    confidences = [r.confidence for r in requirements]
    high_share = sum(1 for c in confidences if c == "high") / len(confidences)
    if high_share > 0.6:
        return "high"
    if high_share > 0.3:
        return "medium"
    return "low"
```

## §11.1 enforcement test (mandatory)

```python
def test_capability_strengths_cannot_override_eligibility_blocker():
    """PRD §11.1: even with strong capability/NAICS, a hard eligibility blocker forces reject."""
    profile = CompanyProfile(
        name="Test Cyber Co",
        capabilities=["cybersecurity", "vulnerability assessment", "compliance audits"],
        naics_codes=["541512"],
        certifications=["CMMC Level 2"],
        clearance_status="none",  # no clearance
    )
    requirements = [
        # Strong capability match
        ExtractedRequirement(type="technical", title="Cybersecurity assessment",
                             value="Perform vulnerability assessments", confidence="high",
                             evidence_snippet="...", source_document="x", page_number=1, is_blocker=False),
        # NAICS match
        ExtractedRequirement(type="eligibility", title="NAICS 541512", value="541512",
                             confidence="high", evidence_snippet="...", source_document="x",
                             page_number=1, is_blocker=False),
        # Hard clearance blocker
        ExtractedRequirement(type="security", title="Secret clearance required",
                             value="All key personnel must hold active Secret clearance",
                             confidence="high", evidence_snippet="...", source_document="x",
                             page_number=2, is_blocker=True, description="Secret clearance"),
    ]

    result = score_fit(profile, requirements)

    # The §11.1 assertion:
    assert result.decision == "reject", \
        f"Expected reject due to clearance blocker; got {result.decision}"
    assert result.score_breakdown.eligibility == 0
    assert any("Secret clearance" in b for b in result.blockers)
    # Capability scored well, but it doesn't matter:
    assert result.score_breakdown.capability >= 15
```

This test must pass before A6 is done. The eval harness (A12) runs the same assertion against the reject fixture.

## LLM rationale (`score_fit_rationale.py`)

Run AFTER `score_fit` produces the decision. The LLM gets the breakdown + decision + profile + requirements and produces:

- `strengths`: list of strings (max 5)
- `weaknesses`: list of strings (max 5)
- `missing_information`: list of strings (fields the agent couldn't extract)
- `recommended_next_action`: one sentence

The LLM is **explicitly told** not to change the decision. Its output merges into the FitScoreOutput before return.

See `prompts/score_fit_rationale.md` for the prompt draft.

## Pitfalls

- **Letting the LLM produce the decision.** Never. The LLM produces prose; the math produces the decision. PRD §11.1 is enforceable only if there's a deterministic gate.
- **Ignoring `is_blocker` flags from extraction.** A5 marks individual requirements as blockers when extraction confidence is high. Honor those in eligibility scoring.
- **Off-by-one on dimension weights.** Sum the breakdown — assert it equals 100 in tests.
- **Soft penalty for "maybe eligible".** Banned. If eligibility is uncertain, score is 0 and a critical blocker is added. Future enhancements can add a "review" path; v1 is binary.
- **Over-rewarding partial NAICS matches.** Match codes by full string equality; partial-prefix matching (e.g., 5415 ≈ 541512) is a stretch.
