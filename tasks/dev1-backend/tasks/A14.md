# A14 — Weekly opportunity email (Resend, PRD §5.14)

> **Status: spec'd, not built.** This task file is the implementation brief once the dev cycle picks it up.

**Goal:** Ship the standalone outbound channel that drops one curated federal opportunity per week into eligible waitlist signups' inboxes via Resend. One-click unsubscribe (RFC 8058). Idempotent per `(email, week_key)`. Dry-run by default. Refuses to send in production unless legal footer is configured.

**PRD references:** §5.14 (full spec), §6 (non-goal wording corrected), §17 Q10 (Resend domain status), §18 (privacy posture for subscribers).
**Depends on:** existing `waitlist_signups` table, existing `score_fit` skill.
**Blocks:** going-live with the public landing's "request access" form (it should reflect the cadence in copy).

## Schema migration (Supabase, not Alembic)

`supabase/migrations/<timestamp>_add_email_preferences_and_logs.sql`:

```sql
set search_path = public, extensions;

-- Extend the existing waitlist_signups table with email-preference columns.
alter table public.waitlist_signups
  add column if not exists weekly_opportunity_enabled boolean not null default true,
  add column if not exists unsubscribed_at timestamptz,
  add column if not exists unsubscribed_reason text,
  add column if not exists bounced_at timestamptz,
  add column if not exists complained_at timestamptz,
  add column if not exists confirmed_at timestamptz,
  add column if not exists last_emailed_at timestamptz;

create index if not exists idx_waitlist_signups_eligible
  on public.waitlist_signups (weekly_opportunity_enabled)
  where unsubscribed_at is null;

-- One curated pick per ISO week.
create table if not exists public.weekly_opportunity_picks (
  id              uuid primary key default extensions.gen_random_uuid(),
  week_key        text not null unique check (week_key ~ '^[0-9]{4}-W[0-9]{2}$'),
  opportunity_id  uuid not null references public.opportunities(id) on delete restrict,
  source          text not null default 'manual' check (source in ('manual', 'llm_auto')),
  notes           text,
  picker_audit    jsonb,
  auto_picked_at  timestamptz,
  created_at      timestamptz not null default now(),
  updated_at      timestamptz not null default now()
);
create trigger trg_weekly_opportunity_picks_updated_at
before update on public.weekly_opportunity_picks
for each row execute function public.set_updated_at();
alter table public.weekly_opportunity_picks enable row level security;

-- Per-recipient idempotency log.
create table if not exists public.weekly_opportunity_email_log (
  id                       uuid primary key default extensions.gen_random_uuid(),
  email_subscription_id    uuid references public.waitlist_signups(id) on delete set null,
  email                    text not null,
  opportunity_id           uuid not null references public.opportunities(id) on delete restrict,
  week_key                 text not null,
  email_type               text not null default 'weekly_opportunity',
  status                   text not null check (status in ('pending', 'sent', 'failed', 'skipped', 'dry_run')),
  resend_message_id        text,
  error_message            text,
  error_class              text,
  attempted_at             timestamptz not null default now(),
  sent_at                  timestamptz,
  created_at               timestamptz not null default now(),
  updated_at               timestamptz not null default now(),
  unique (email, week_key, email_type)
);
create index if not exists idx_weekly_opportunity_email_log_week_status
  on public.weekly_opportunity_email_log (week_key, status);
create index if not exists idx_weekly_opportunity_email_log_opportunity
  on public.weekly_opportunity_email_log (opportunity_id);
create trigger trg_weekly_opportunity_email_log_updated_at
before update on public.weekly_opportunity_email_log
for each row execute function public.set_updated_at();
alter table public.weekly_opportunity_email_log enable row level security;
```

RLS: both new tables enable RLS with no public policies — only the service role (used by FastAPI) can read/write.

## Eligibility query

```python
async def get_eligible(self, week_key: str, *, batch_size: int = 500):
    return await (
        self.client.table("waitlist_signups")
        .select("id, email, created_at")
        .eq("weekly_opportunity_enabled", True)
        .is_("unsubscribed_at", None)
        .is_("bounced_at", None)
        .is_("complained_at", None)
        .order("created_at")
        .limit(batch_size)
        .execute()
    )
```

Per-row, the job calls `weekly_opportunity_email_log.claim(email, week_key)` to atomically reserve the slot. If `null` returned, it was already taken — skip.

## Unsubscribe token

```python
import hmac, hashlib, base64

def sign(subscription_id: str, email: str, secret: str) -> str:
    msg = f"{subscription_id}:{email}".encode()
    sig = hmac.new(secret.encode(), msg, hashlib.sha256).digest()
    return base64.urlsafe_b64encode(sig).rstrip(b"=").decode()

def verify(token: str, subscription_id: str, email: str, secret: str) -> bool:
    expected = sign(subscription_id, email, secret)
    return hmac.compare_digest(expected, token)
```

URL: `${EMAIL_PUBLIC_BASE_URL}/email-subscriptions/unsubscribe?sid=<id>&token=<token>` — `sid` and `token` together prevent enumerate-and-tamper.

## Auto-picker safety filters

`api/email/safety_filters.py`:

```python
CLEARANCE_KEYWORDS = (
    "secret", "top secret", "clearance", "cleared personnel",
    "cui", "controlled unclassified", "itar", "classified",
)
SAFE_SET_ASIDES = (None, "Total Small Business", "")

def passes_safety_filters(opp: dict, *, today: date, naics_allowlist: set[str]) -> tuple[bool, list[str]]:
    reasons = []
    if opp.get("set_aside") not in SAFE_SET_ASIDES:
        reasons.append(f"set_aside_too_narrow:{opp['set_aside']}")
    if opp.get("due_date") and opp["due_date"] < today + timedelta(days=14):
        reasons.append("deadline_too_soon")
    desc = (opp.get("description") or "").lower()
    matched = [k for k in CLEARANCE_KEYWORDS if re.search(rf"\b{re.escape(k)}\b", desc)]
    if matched:
        reasons.append(f"clearance_keywords:{','.join(matched)}")
    if naics_allowlist and opp.get("naics") not in naics_allowlist:
        reasons.append(f"naics_outside_allowlist:{opp.get('naics')}")
    if not opp.get("attachments"):
        reasons.append("no_attachments")
    pop = (opp.get("place_of_performance") or "").lower()
    if pop and not _is_us_pop(pop):
        reasons.append("non_us_place_of_performance")
    return (not reasons, reasons)
```

## Cron route auth

```python
from fastapi import Header, HTTPException
import secrets

async def require_internal(authorization: str = Header(None)) -> None:
    expected = f"Bearer {settings.internal_api_key}"
    if not settings.internal_api_key:
        raise HTTPException(503, "INTERNAL_API_KEY not configured")
    if not authorization or not secrets.compare_digest(authorization, expected):
        raise HTTPException(401, "Invalid bearer")
```

Apply to both cron routes. nginx `/internal/*` → 404 at the edge; FastAPI is reachable only on `127.0.0.1:8000` in production so a public hit can't reach the route anyway.

## Pitfalls

- **Sending to non-account-owner before domain verification.** Resend sandbox returns "you can only send testing emails to your own email address" — confirmed in the v1.2.6 dev test (2026-05-10). Verify a domain at resend.com/domains before flipping `EMAIL_DRY_RUN=false`.
- **Plaintext token in URL.** Don't put the raw `subscription_id` in the URL alongside the HMAC — bind both via the signature, then verify the pair. Don't include the email; the HMAC is enough.
- **Auto-picker emails a fixture.** `EMAIL_USE_FIXTURES_FOR_AUTO_PICK` defaults to `false`; the picker must filter out fixture-sourced opportunities by inspecting their `source_url` or a fixture flag.
- **PRD §11.1 spirit applied to a faceless audience.** Auto-picker must refuse narrow set-asides (8(a)/HUBZone/etc.) since we don't have per-subscriber certifications.
- **Resend rate limits in tests.** Always use the recording fixture; never let a test reach `resend.Emails.send`.
