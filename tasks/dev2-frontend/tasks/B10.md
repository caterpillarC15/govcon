## Pitfalls

- **Past performance threshold not specific enough.** "Significant past performance" won't trigger the gap detection. Use a concrete dollar value in the source text.
- **Capability gap conflated with past-performance gap.** They're different. This fixture is past-performance-only; capability matches.
- **Demo company's $1.5M past performance.** If you change B13's number, this fixture's expected band shifts. Co-evolve.
